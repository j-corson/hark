      Instructions for Claude

      How Claude should organise this document. This applies to the current session only.

      Start from an agenda

      One item per line or bullet. Indented lines under an item are notes on it, and a “# Title” line names the document. If this session already has something in it, a new session is started and this one is kept.

      Meeting time

      Claude uses this when you ask “what else do we need to cover?”, and the room screen counts down to it. You can also say it out loud: “Claude, we finish at half eleven.”

      The reminder shows on the room screen and in the Research panel, only while hark is listening.

      Collections

      Documents Claude can search when you ask, for example “Claude, what did we decide in the last catch-up?” GitHub repos are fetched again before a search if they haven't been checked for five minutes. Folders on your own computer are read as they are, and can be added with hark --add-corpus FOLDER. Each session searches only the collection picked in the Research panel, in the menu next to Look something up.
